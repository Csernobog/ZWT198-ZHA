# Lovelace dashboard

**Included:** [`zwt198_editor.yaml`](zwt198_editor.yaml), the working card YAML pasted from the HA dashboard editor. Set the `title-card.entity` climate entity to match your thermostat.

The editor uses three helpers, Pyscript load/save actions, an Expander Card and ApexCharts Card. It switches the chart between weekday (6 periods) and weekend (2 periods) based on the selected slot.
