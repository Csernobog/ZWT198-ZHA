# Pyscript editor source

**Included locally tested source:**

`/config/pyscript/zwt198_schedule.py`

Set `IEEE = "REPLACE_WITH_YOUR_DEVICE_IEEE"` to your own ZHA IEEE before use. The original device address was redacted for public release.

It provides the `pyscript.zwt198_schedule_load` and `pyscript.zwt198_schedule_save` services, publishes `pyscript.zwt198_schedule` for chart rendering, and performs the tested RAW DP109 write.
